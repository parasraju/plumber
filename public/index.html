Inspection Categories

Deterministic checks across five core engineering disciplines.

leaks_and_secrets.log

CRITICAL

Scans for leaked API keys, tokens, and committed credentials.

  • OpenAI, Anthropic, AWS, Stripe keys
  • Plaintext passwords and database strings
  • Real production secrets in committed .env files

clogs_and_stubs.diff

HIGH

Finds AI agent diff elisions and silent failure blocks.

  • // ... existing code ... truncation tells
  • Silent error swallowing (except: pass, catch {})
  • Unimplemented stub functions & robotic step comments

ai_slop_tells.css

MEDIUM

Flags the aesthetic defaults generated by frontier models.

  • Purple-to-pink gradient defaults (from-purple-600)
  • Heavy neon blur glow box-shadows
  • Chatbot conversational residue (“As an AI model...”)

pipes_and_deps.json

HIGH

Detects hallucinated libraries and broken links.

  • Hallucinated package imports not in registry
  • Undeclared dependencies missing from manifest
  • Dead links using href="#" or javascript:void(0)

joints_and_ally.html

MEDIUM

Enforces semantic HTML and reliable test verification.

  • Clickable <div> elements without keyboard roles
  • Focus outlines stripped with outline: none
  • Empty unit tests containing zero assertions

run plumber everywhere

Integrate directly into your terminal workflow or automated CI pipeline.

Inspect local directories or public repositories directly from your terminal:

python -m plumber scan .                       # inspect current repo
python -m plumber scan owner/repo              # stream and inspect GitHub repo
python -m plumber scan . --format json         # export structured JSON report

Configure Claude Code to automatically check modified files as it works:

# In your Claude Code settings or AGENTS.md
python -m plumber scan . --fail-on high        # validates changed lines

Cursor rules and MCP integration configuration:

{
  "mcpServers": {
    "plumber": {
      "command": "python",
      "args": ["-m", "plumber", "mcp"]
    }
  }
}

Automate repository hygiene enforcement on pull requests:

# .github/workflows/plumber.yml
name: Plumber Hygiene Audit
on: [pull_request]
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python -m plumber scan . --fail-on high
